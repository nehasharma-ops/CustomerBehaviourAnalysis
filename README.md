# CustomerBehaviourAnalysis
End-to-end pipeline from raw data to interactive insights using Pandas, PostgreSQL, and Power BI delivers a comprehensive analytical foundation.  • Focus on converting loyal customers to subscribers and growing new customer base • Optimise discounting strategies while leveraging high customer satisfaction products 
# 📊 Data Analytics Project

## 🔍 Overview

This project focuses on analyzing customer behavior data using Python, SQL, and Power BI. It covers the complete data analysis pipeline—from data loading and cleaning to visualization and reporting. The goal is to extract meaningful insights and present them in a clear, business-friendly format.

---

## 📁 Dataset

* Source: Customer behavior dataset (CSV format)
* Contains information such as:

  * Customer demographics
  * Purchase history
  * Discounts and promo usage
  * Product categories
* Data is loaded and processed using Python.

---

## 🛠️ Tools & Technologies

* **Python** (Pandas, NumPy, Matplotlib, Seaborn)
* **PostgreSQL / MySQL / SQL Server** (for querying and data storage)
* **Power BI** (dashboard creation and visualization)
* **MS PowerPoint / Gamma** (presentation creation)

---

## ⚙️ Steps Performed

### 1. Data Loading

* Imported dataset using Pandas
* Connected Python with SQL database using SQLAlchemy / psycopg2

### 2. Data Cleaning

* Handled missing values
* Removed duplicates
* Standardized column names
* Fixed data types

### 3. Exploratory Data Analysis (EDA)

* Analyzed distributions and trends
* Identified patterns in customer behavior
* Used visualizations like:

  * Histograms
  * Bar charts
  * Correlation heatmaps

### 4. SQL Analysis

* Created tables in PostgreSQL / MySQL
* Wrote queries to extract insights such as:

  * Top-selling products
  * Discount usage trends
  * Customer segmentation

### 5. Dashboard Creation

* Built an interactive **Power BI dashboard**
* Key features:

  * KPIs (Revenue, Orders, Discounts)
  * Filters and slicers
  * Visual insights for decision-making

### 6. Reporting

* Created a professional presentation using **Gamma / PowerPoint**
* Summarized key insights and business recommendations

## ▶️ How to Run

1. Clone the repository
2. Install required libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn sqlalchemy psycopg2
   ```
3. Load dataset in Python
4. Run data cleaning and EDA scripts
5. Connect to SQL database and execute queries
6. Open Power BI file (.pbix) to view dashboard
7. Review presentation for summary insights
